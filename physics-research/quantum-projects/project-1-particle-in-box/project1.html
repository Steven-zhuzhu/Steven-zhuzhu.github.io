Advanced Computational Quantum Mechanics: Mathematical Foundations and Numerical Implementation

Project Work

Quantum mechanics is the core direction of my physics research. Each case follows the same three steps: derive the model on paper, implement it in Python, and compare the number the code produces with the number theory gives.

Hydrogen — the closed-form wavefunctions ψₙₗₘ, with |ψ|² slices in three planes, 3D electron clouds, radial distribution functions and phase plots. Normalization and ⟨r⟩ agree with the analytic values, which makes hydrogen the exact reference against which the other two cases are measured.

Helium — electron–electron repulsion treated explicitly, by variational Monte Carlo (hydrogenic and Hylleraas‑type trial functions) and by Hartree–Fock.

H₂O — Hartree–Fock SCF written from the integrals up: overlap, kinetic and nuclear‑attraction matrices, 26,796 two‑electron integrals after permutational symmetry, the Fock matrix, and the molecular orbitals.

Everything is written in Python — NumPy and SciPy for the linear algebra, special functions and optimization, Matplotlib for the figures.

Helium and H₂O are where the numerics do the real work: both are still being corrected against their reference values, and each script prints the comparison, so the size of the error is visible rather than assumed.

These projects are the foundation for later work in quantum computing and quantum information.
